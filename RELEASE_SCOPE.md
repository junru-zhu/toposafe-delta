# Release Scope

This GitHub repository is a private research snapshot.

Included:

- anonymous paper source and PDF;
- synthetic task catalogs;
- experiment implementation and tests;
- frozen protocols, manifests, raw model outputs, deterministic validation,
  aggregate analyses, failed gates, and recovery packages;
- literature and claim-integrity records.

Excluded:

- AWS, GitHub, or other service credentials;
- virtual environments, caches, local temporary files, and compiled Python
  bytecode;
- duplicated manuscript ZIP files and LaTeX build intermediates;
- unrelated SwarmSafe experiment families;
- local reviewer files and absolute workstation paths.

No open-source or dataset license is granted by this snapshot. Public release,
redistribution, or venue submission requires a separate licensing, anonymity,
and raw-output review.
