Title:
When Messages Become Authority: Separating Communication, Authorization, and Execution in Multi-Agent LLMs

Abstract:
Language is not merely content in a multi-agent LLM system: a message can be routed, treated as authorization, and converted into a protected action. Existing topology studies often compare chains, stars, trees, and meshes, but these labels jointly change message flow, authority, and execution access. We represent these relations as separately intervenable communication, authority, and execution graphs, and define the authority cut kappa_A as the minimum number of independent principals that must deviate to construct a policy-valid false authorization proof. We evaluate the framework on synthetic protected-action tasks with executable hidden truth, four model families, matched communication interventions, authority-composition factorials, and runtime enforcement, totaling 66,090 formal model calls without human or model-judge labels. Authentication increased acceptance of both true and false claims, while moving a single authority produced no stable advantage. Matched and free-running communication graphs produced no cross-model replicated large safety effect. Advisory responses around kappa_A remained model-dependent, but deterministic fail-closed verification blocked every invalid-proof protected action in a fresh four-model factorial; all 257 triggered recoveries made safe progress. Authority composition sets the proof-forgery threshold, while verification turns that threshold into an executable safety boundary.
